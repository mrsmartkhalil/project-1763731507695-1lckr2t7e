Click here: **[Deploy to Vercel](https://vercel.com/new/clone?repository-url=https://github.com/mrsmartkhalil/project-1763731507695-1lckr2t7e)**

2. Click "Sign Up" or "Log In" (use GitHub account)
3. Click "Add New..." → "Project"

### Step 2: Import Your Repository

1. Find: `mrsmartkhalil/project-1763731507695-1lckr2t7e`
2. Click "Import"

### Step 3: Configure (Auto-detected)

Vercel will automatically detect:
- Framework: Next.js
- Build Command: `npm run build`
- Output Directory: `.next`
- Install Command: `npm install`

**Just click "Deploy"!** ✨

Vercel will:
- Install dependencies
- Build your project
- Deploy to production

## 🔧 Post-Deployment Setup

### 1. Custom Domain (Optional)

In Vercel Dashboard:
1. Go to your project
2. Settings → Domains
3. Add your custom domain (e.g., `muhammadafaq.com`)
4. Follow DNS instructions

### 2. Update Content

Visit `/admin` to:
- Add your real projects
- Write blog posts
- Update information

### 3. Environment Variables (If needed)

In Vercel:
1. Settings → Environment Variables
2. Add any secrets or API keys
3. Redeploy

## 🔄 Automatic Deployments

Now, every time you push to GitHub:
```bash
git add .
git commit -m "Update content"
git push origin main
```
Vercel will automatically redeploy! 🚀

## 🎨 Customize Your Site

Update these files:

4. **Styling**: `app/globals.css`

## ⚡ Alternative: Netlify

Don't want Vercel? Use Netlify:

1. Go to https://netlify.com
2. "Add new site" → "Import from Git"
3. Choose GitHub → Select your repo
4. Click "Deploy"
